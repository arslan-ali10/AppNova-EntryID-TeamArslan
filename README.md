# CampusFind – Team Arslan

## Project Description

CampusFind is an Android-based Lost and Found application designed to help students find lost belongings and report items found on campus.

The application provides a simple platform where users can register, log in, report lost or found items, and view reported items. It aims to make communication between students easier and improve the chances of returning lost belongings to their owners.

## Features

- **User Registration and Login:** Users can create an account and securely log in.
- **Home Screen:** Displays recently reported lost and found items.
- **Report Lost Items:** Users can report items they have lost.
- **Report Found Items:** Users can report items they have found.
- **Item Details:** Users can view information about reported items.
- **GPS Location:** Supports adding the current location when reporting an item.
- **Nearby Items:** Helps users find reported items near their location.
- **Google Maps:** Allows users to view an item's location on a map.
- **Search and Filter:** Helps users search and filter reported items.
- **Return Status:** Supports marking an item as returned.
- **User Profile:** Provides basic user information and logout functionality.

## Technologies Used

- **Programming Language:** Java
- **User Interface:** XML
- **Development Environment:** Android Studio
- **Database:** SQLite
- **Location Services:** Android Location Services
- **Maps:** Google Maps through map intents

## Installation and Setup

1. Download or clone the project.
2. Open Android Studio.
3. Select **Open** and choose the CampusFind project folder.
4. Wait for Gradle Sync to complete.
5. Connect an Android device or start an emulator.
6. Click **Run** to install and launch the application.

## Database

CampusFind uses SQLite to store user accounts and reported item information locally on the device.
